 PROJE NEDIR
--------------------------------------------------------------------------
FULL Servis: 4 makineli dagitik modem stres testi. Hepsi ayni modeme baglanir,
es zamanli yuk basar (ping/youtube/iperf/torrent/wifi). Modem cokmeden dayanirsa
firmware basarili sayilir.
- Linux Sunucu (orkestrator + dashboard, port 8770)  rol: ping, youtube
- MAC Kablo (iperf SERVER)                            rol: youtube,ping,iperf_server
- WINDOWS WiFi                                        rol: youtube,ping,torrent,wifi_track
- MAC WiFi  (iperf CLIENT)                            rol: youtube,ping,iperf,wifi_track
Kod: fullservice-backend/  (server/, agent/, common/, common/runners/)
GRK (grk-automation/) = ayri, canli, SALT-OKUNUR referans. ASLA dokunma.

YENI/DEGISEN DOSYALAR:
  server/db_service.py        (YENI) copy_ tablolarina yazan fonksiyonlar.
                              En ustte TABLO ADI sabitleri var — birlestirmede
                              copy_test_session -> test_session vb. yapmak icin
                              sadece o 6 sabiti degistir.
  common/protocol.py          + ResultReport modeli (agent -> sunucu sonuc ozeti)
  common/runners/base.py      RunContext'e result callback eklendi (kind, stats)
  agent/test_executor.py      test bitince /api/result'a ozet POST eder
  server/main.py              + POST /api/result endpoint
  server/orchestrator.py      start_session'da copy_test_session olusturur;
                              record_result ile ping/iperf/wifi satirlarini yazar;
                              stop_session'da bitis zamanini gunceller
  common/runners/ping_runner.py   bitince istatistik (total/success/loss/min/max/
                                  avg/median/std) hesaplayip ctx.result ile gonderir
  common/runners/iperf_runner.py  sender/receiver Mbps hesaplayip gonderir
  common/runners/wifi_track_runner.py  ornekleri toplayip ozet gonderir
  common/runners/wifi_util.py     + format_sample_line yardimcisi

AKIS: agent runner test biter -> ctx.result(kind, stats) -> /api/result ->
orchestrator.record_result -> db_service.save_* -> copy_ tablosu.
Sunucu-yerel testler (Linux) ayni record_result'i dogrudan cagirir.
DB yoksa (SessionLocal None) her sey sessizce atlanir, testler yine calisir.

test_name her satirda 'FULL_SERVIS'. node_name = config'deki log_name
(server=LINUX, mac_cable=MAC_ETH, mac_wifi=MAC_WIFI, win_wifi=WIN_WIFI).
